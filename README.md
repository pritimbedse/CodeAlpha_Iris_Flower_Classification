# Iris Flower Classification 🌸

## Project Overview
This project was completed as part of the CodeAlpha Data Science Internship.

The project uses Machine Learning to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

## Dataset
The Iris dataset is used for this classification project.

## Result
The Support Vector Machine (SVM) model achieved the best test accuracy of **96.7%**.
